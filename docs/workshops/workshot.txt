#topic 1: Modernizing APIs for AI Agents: From OpenAPI to MCP
duration: 45 minutes
description: Most enterprises already have well-documented REST APIs, but AI agents cannot reliably use them without an interface designed for tool discovery, structured invocation, and safe runtime interaction. This session shows how API architects and integration engineers can transform existing OpenAPI-described services into MCP-based, AI-consumable tools, where automation helps, where curation is essential, and how to preserve governance, security, and observability along the way.

Through a practical walkthrough, the session compares OpenAPI and MCP, demonstrates automatic MCP server generation from an existing API contract, and explains how to refine tool semantics so agents can use them effectively rather than blindly exposing every endpoint as a tool. Attendees will also see how to apply guardrails such as selective exposure, policy controls, and runtime monitoring, which are increasingly important because MCP adoption is moving faster than enterprise governance models built for human-driven API traffic.

#topic 2: Beyond API Governance: Securing AI Agents, MCP Servers, and Enterprise Integrations
duration: 45 minutes
description: As organizations rapidly integrate Large Language Models (LLMs), AI agents, MCP servers, and AI gateways into enterprise ecosystems, traditional API governance models are no longer sufficient. AI systems introduce new challenges including prompt injection attacks, uncontrolled tool access, data leakage, shadow AI adoption, compliance risks, and lack of observability.

This demo-led session explores how API and integration teams can extend established governance practices into the age of AI. Through real-world architectural patterns and live demonstrations, attendees will learn how to govern AI interactions across APIs, MCP servers, AI gateways, and backend enterprise systems.

The session showcases practical approaches for implementing policy enforcement, access control, auditability, observability, and responsible AI controls without slowing innovation. Participants will leave with a blueprint for building enterprise-grade AI integration platforms that are secure, compliant, and production-ready.

#topic 3: Architecting the Agentic Enterprise: Middleware, Durable State, and Event-Driven AI
duration: 45 minutes
description: The generative AI landscape is rapidly shifting from stateless, synchronous chat applications to autonomous, long-running, multi-agent workflows. However, integrating non-deterministic AI agents into deterministic enterprise infrastructure presents massive architectural challenges regarding state, reliability, and governance.

This 45-minute demo-led workshop bridges the gap between theoretical multi-agent systems and robust enterprise middleware. We will explore how to treat agents as resilient, event-driven microservices. Through a live architectural demonstration of an "Autonomous System Resolver," attendees will see the exact plumbing required to take agents to production. We will cover exposing legacy systems to LLMs securely via the Model Context Protocol (MCP) and API gateways, triggering agentic cognition via Kafka event streams, and managing long-running, multi-week agent processes without state loss using Temporal and LangGraph. Finally, we will demonstrate how to enforce safety through strict human-in-the-loop (HITL) execution pauses before high-stakes API commits.


#topic 4: The Day the Agent Broke the Bank: Implementing Triple-Gate Architecture & A2A Security for Autonomous AI Workloads
duration: 135 minute
description:Traditional API gateways protect systems from fast humans, but they are fundamentally blind to autonomous AI agents. When an enterprise deploys agentic workflows (via frameworks like LangGraph or CrewAI) and exposes internal business APIs as "Tools," standard REST security fails. Prompt injections don't violate network schemas, and non-deterministic agentic reasoning loops routinely bypass traditional rate limits, risking massive financial and data liability.This session uses a "live incident response" storytelling approach to deconstruct a high-consequence system compromise: The Day NegotiatorBot Broke the Bank. Through the lens of a multi-million-dollar automated exploit driven by a subtle prompt injection, we will map out why legacy OAuth and standard API proxies failed to stop the breach.Moving from forensic analysis to modern architecture, attendees will learn how to systematically remediate the vulnerability by deploying a production-ready Triple-Gate Architecture. We will walk through the mechanical deployment of three distinct security perimeters: defending the inference boundary (AI Gateway), governing capability execution (Tool/MCP Gateway), and securing micro-scoped identity propagation at the infrastructure layer (Standard API Gateway) via OAuth Token Exchange ($RFC\ 8693$). Finally, we will demonstrate how to achieve deep observability across recursive agentic loops using modern OpenTelemetry GenAI span tracing. Attendees will leave with a concrete architectural blueprint to safely govern autonomous Agent-to-Agent (A2A) interactions in production.
